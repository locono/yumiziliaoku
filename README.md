# 🌽 玉米资料库

> 一站式考公资料导航站 · yumiziliaoku.com

玉米资料库是一个面向考公人群的静态导航网站，把散落在各处的课程目录、笔记网盘和更新动态集中到一页，帮备考的人少绕弯路、快速找到需要的资料。

## 站点内容

- **考公课程目录** —— 覆盖公务员、国考省考、教师、事业、文职、三支、社工、英语、财会、司法十大类目
- **免费笔记网盘群** —— 海量笔记资料随存随取
- **课程更新日志** —— 课程更新动态实时可查

## 特色

- 单文件纯静态页面，零外部依赖，打开即用
- 自适应手机、平板、PC，各设备自动缩放
- 顶部导航 + 当天日期显示，悬浮按钮一键返回顶部
- 页尾提供微信公众号「玉米资料」「玉米君资料库」二维码，扫码直接关注
- 支持一键复制联系 QQ

## 部署

直接将 `index.html` 上传至 Cloudflare Pages（或任意静态托管平台）即可访问，无需构建、无需服务器。
